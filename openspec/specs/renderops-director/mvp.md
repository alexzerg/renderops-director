# RenderOps Director MVP Knowledge

Version: 0.1.4

For an Agentic Cinema Grafana-track submission, distinguish production rendering from generic SRE and premiere-streaming control rooms. The strongest outcome is a shot-level decision: identify failed frames and render passes, correlate GPU/asset/log/trace evidence, compare full rerender with a bounded canary, quantify deadline risk, and retain human approval for mutation.

Use Google ADK `McpToolset` directly. Support hosted Streamable HTTP for interactive OAuth and the official OSS `mcp-grafana` stdio process for unattended Cloud Run. Maintain an explicit demo/live boundary and expose only read tools until approval-backed actions exist.
